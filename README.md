# React Portfolio — COMP-229 Assignment 1

## Included pages
- Home
- About Me
- Projects
- Education
- Services
- Contact Me

## Run locally
1. Install Node.js.
2. Open this folder in VS Code/terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

Run `npm run build`.
